# OGameBeyond Lua Game Scaffold

This is an original Lua game framework inspired by large-scale space strategy UI and economy loops.
It is not the original OGame source code and does not reuse proprietary implementation details.

## Modules

- `engine/` - core loop, events, timers, input, and scene switching
- `game/` - universe, planets, fleets, economy, research, combat, and serialization
- `ui/` - top bar, side panels, bottom panels, overview, galaxy, fleet, and widgets
- `docs/` - design notes and UML sketches

## Entry Point

- `main.lua` starts the engine and the game state.
