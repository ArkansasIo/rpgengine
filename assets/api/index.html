ECS - Entity Component System

UE5-inspired ECS with zero virtual dispatch. Entities are lightweight IDs owning data-only components.

namespace arclight { EntityManager mgr; EntityID e = mgr.CreateEntity(); auto& t = mgr.AddComponent<TransformComponent>(e); t.SetPosition(float3(100, 0, 200)); auto* h = mgr.GetComponent<HealthComponent>(e); h->ApplyDamage(50.0f); }

EntityManager

MethodReturnsDescription
CreateEntity()EntityIDSpawn a new entity
DestroyEntity(id)voidRemove entity and all components
AddComponent<T>(id)T&Attach component to entity
GetComponent<T>(id)T*Get component (nullptr if missing)

Quick Start

#include "ArcLightEngine.h" using namespace arclight; int main() { ArcLightEngine engine; engine.Init(); EntityID unit = engine.SpawnUnit(float3(0,0,0), 0); while (running) { float dt = GetDeltaTime(); engine.Update(dt); Render(); } engine.Shutdown(); }
