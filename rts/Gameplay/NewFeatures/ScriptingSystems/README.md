# Scripting Systems

This folder groups the scripting layer for gameplay and engine-facing feature work.

## Subfolders

- `OOScript/` - object-oriented Lua scripting helpers and class-style gameplay code
- `GameScripts/` - per-game scripts, controllers, and feature scripts
- `Runtime/` - script loading, lifecycle, and execution helpers
- `Docs/` - UML notes, coding guidance, and scripting references

These folders are meant to organize scripting features before they are integrated into the main gameplay runtime.
