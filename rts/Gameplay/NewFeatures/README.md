# Gameplay New Features

This folder is a staging area for new gameplay and engine feature work.

## Subfolders

- `Logic/` - shared gameplay logic and decision flow
- `GameLogic/` - higher-level game rules and feature behavior
- `MechanicsLogic/` - mechanics, cooldowns, combat rules, and core systems
- `Functions/` - reusable helper functions for gameplay code
- `GameEngine/` - engine-facing gameplay integration code
- `GameEngineFunctions/` - engine helper functions for gameplay systems
- `GameEngineLogic/` - logic that sits between the engine and gameplay rules
- `ScriptingSystems/` - Lua scripting, OOP helpers, runtime, and docs
- `Other/` - temporary or cross-cutting feature work

Use these folders to keep new feature code separated from the existing gameplay module until it is ready to be integrated more deeply.
